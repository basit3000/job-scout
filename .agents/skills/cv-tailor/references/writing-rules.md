# Shared writing guidance

Use supported facts, precise wording and the candidate's preferred language.
Separate employment from projects and distinguish measured outcomes from
implementation details. Missing dates, metrics or qualifications stay questions.

Tailor emphasis to the posting without copying unsupported requirements. Preserve
useful existing text. A summary, section order, tone, punctuation and sign-off are
candidate choices, not universal rules.

Use the supplied task instructions, Memory preferences and prompt settings snapshot.
Outside a staged workflow, read `prompts/local.json` for local wording and format.
The tracked `prompts/example.json` demonstrates customization without candidate
facts. Keep style suggestions optional unless they violate an explicit requirement.

Keep the document complete and readable. The host checks source integrity,
rendered output and the configured page limit before publication.
