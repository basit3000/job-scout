# Optional cover-letter notes

Facts the letter may use **when they match the posting**. At most two per letter.
Never turn these into extra years of employment. Never praise the company.
Write them in simple English.

Copy this file to `cv/cover-letter-notes.md` (gitignored) and replace every `YOUR_*`.
Setup does that copy on first run and will not overwrite an existing notes file.

## YOUR_NOTES_TOPIC_1

YOUR_ONE_SENTENCE_OF_BACKGROUND

Use when the posting mentions YOUR_KEYWORD_1 or YOUR_KEYWORD_2.

## YOUR_NOTES_TOPIC_2

YOUR_OTHER_SENTENCE_OF_BACKGROUND

Use when the posting mentions YOUR_KEYWORD_3.
