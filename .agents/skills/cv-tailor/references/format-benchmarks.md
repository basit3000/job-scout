# Format review

Check reading order, text extraction, headings, spacing and legibility in the
actual output. Use the supplied layout and configured page limit. Do not assume
that every candidate needs the same sections, photo policy or number of pages.

Research current market guidance when requested or when a specific unresolved
format decision needs evidence. Routine tailoring does not require a new research
pass. External guidance is advisory: it cannot establish candidate facts or
justify publication.

Report observed parsing or layout issues. A heuristic ATS check is not an ATS
pass probability or a guarantee of recruiter acceptance.
